## 📋 升级步骤

### 1. 备份当前配置
```bash
cp package.json package.json.backup
```

### 2. 卸载可能冲突的依赖
```bash
npm uninstall element-plus @element-plus/icons-vue dexie highlight.js markdown-it marked uuid @microsoft/fetch-event-source
```

### 3. 安装推荐版本
```bash
# 安装核心依赖的推荐版本
npm install element-plus@^2.2.36 @element-plus/icons-vue@^2.1.0
npm install dexie@^3.2.4 highlight.js@^11.8.0
npm install markdown-it@^13.0.2 marked@^9.1.6
npm install uuid@^9.0.1 @microsoft/fetch-event-source@^1.0.6

# 安装兼容性工具
npm install --save-dev @vitejs/plugin-legacy@^5.4.2 terser@^5.36.0
npm install --save-dev @babel/core@^7.25.9 @babel/preset-env@^7.25.9
npm install --save-dev @babel/plugin-transform-runtime@^7.25.9
npm install --save-dev @babel/plugin-proposal-optional-chaining@^7.21.0
npm install --save-dev @babel/plugin-proposal-nullish-coalescing-operator@^7.18.6
npm install --save-dev core-js@^3.39.0 regenerator-runtime@^0.14.1

# 更新类型定义
npm install --save-dev @types/uuid@^9.0.8 @types/markdown-it@^13.0.7
```

### 4. 更新配置文件

参考 `docs/elementui.md` 中的 Vite 和 Babel 配置。

## ⚠️ 注意事项

### Element Plus 版本差异
- **2.2.36 vs 2.4.4**：可能缺少一些最新特性和组件
- **API 变更**：检查是否有 breaking changes
- **样式差异**：可能需要调整部分样式

### 功能影响评估
1. **检查 Element Plus 组件使用**：确认所用组件在 2.2.36 中可用
2. **测试 Markdown 渲染**：markdown-it 13.x 可能有功能差异
3. **验证数据库操作**：Dexie 3.x 的 API 可能有变化
4. **UUID 生成测试**：确认 UUID 9.x 满足需求

## 🚀 快速执行脚本

创建一个快速升级脚本 `upgrade-compatibility.sh`：

```bash
#!/bin/bash
echo "开始浏览器兼容性升级..."

# 备份
cp package.json package.json.backup
echo "✅ 已备份 package.json"

# 卸载高风险依赖
echo "🗑️ 卸载高风险依赖..."
npm uninstall element-plus @element-plus/icons-vue dexie highlight.js markdown-it marked uuid @microsoft/fetch-event-source

# 安装推荐版本
echo "📦 安装推荐版本..."
npm install element-plus@^2.2.36 @element-plus/icons-vue@^2.1.0 dexie@^3.2.4 highlight.js@^11.8.0 markdown-it@^13.0.2 marked@^9.1.6 uuid@^9.0.1 @microsoft/fetch-event-source@^1.0.6

# 安装兼容性工具
echo "🔧 安装兼容性工具..."
npm install --save-dev @vitejs/plugin-legacy@^5.4.2 terser@^5.36.0 @babel/core@^7.25.9 @babel/preset-env@^7.25.9 @babel/plugin-transform-runtime@^7.25.9 @babel/plugin-proposal-optional-chaining@^7.21.0 @babel/plugin-proposal-nullish-coalescing-operator@^7.18.6 core-js@^3.39.0 regenerator-runtime@^0.14.1

# 更新类型定义
echo "📝 更新类型定义..."
npm install --save-dev @types/uuid@^9.0.8 @types/markdown-it@^13.0.7

echo "✅ 升级完成！请参考 docs/elementui.md 更新配置文件"
echo "⚠️ 记得测试应用功能是否正常"
```

使用方法：
```bash
chmod +x upgrade-compatibility.sh
./upgrade-compatibility.sh
```
