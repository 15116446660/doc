# PMS系统唤起第二个系统的集成方案

## 1. 业务场景分析

### 1.1 现状梳理
- **PMS系统**：基于LDAP登录的项目管理系统
- **第二个系统**：基于Spring Boot + LDAP的文档处理系统（支持本地账号和LDAP双重认证）
- **业务需求**：PMS需要唤起第二个系统的指定功能页面

### 1.2 核心挑战
1. **身份认证同步**：两个系统都支持LDAP，但认证会话独立
2. **权限传递**：PMS用户权限如何映射到第二个系统
3. **安全性**：防止未授权访问和会话劫持
4. **用户体验**：实现单点登录效果，避免重复登录

## 2. 技术方案设计

### 2.1 整体架构

```
┌─────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   PMS系统   │    │   认证中心/网关   │    │   第二个系统     │
│  (LDAP)     │◄──►│   (JWT/Token)   │◄──►│ (Spring Boot)   │
└─────────────┘    └─────────────────┘    └─────────────────┘
       │                     │                       │
       └─────────────────────┼───────────────────────┘
                             ▼
                    ┌─────────────────┐
                    │   LDAP服务器     │
                    │  (统一用户源)    │
                    └─────────────────┘
```

### 2.2 方案选择

#### 方案一：JWT Token传递（推荐）
- **原理**：PMS生成包含用户信息的JWT Token，传递给第二个系统
- **优点**：安全性高、无状态、易于扩展
- **适用场景**：系统间信任度高，需要传递详细用户信息

#### 方案二：临时授权码
- **原理**：PMS生成临时授权码，第二个系统通过授权码获取用户信息
- **优点**：安全性极高、授权码一次性使用
- **适用场景**：对安全要求极高的场景

#### 方案三：共享Session
- **原理**：两个系统共享Session存储（如Redis）
- **优点**：实现简单
- **缺点**：耦合度高、扩展性差

### 3.2 PMS系统实现

#### 3.2.1 JWT生成服务

```java
@Service
public class CrossSystemAuthService {
    
    @Value("${jwt.secret}")
    private String jwtSecret;
    
    @Value("${jwt.expiration:3600}") // 1小时过期
    private int jwtExpiration;
    
    public String generateCrossSystemToken(User user, String targetPage, Map<String, Object> context) {
        Date now = new Date();
        Date expiry = new Date(now.getTime() + jwtExpiration * 1000);
        
        Map<String, Object> userInfo = new HashMap<>();
        userInfo.put("username", user.getUsername());
        userInfo.put("email", user.getEmail());
        userInfo.put("display_name", user.getDisplayName());
        userInfo.put("department", user.getDepartment());
        userInfo.put("roles", user.getRoles().stream().map(Role::getName).collect(Collectors.toList()));
        userInfo.put("permissions", getUserPermissions(user));
        userInfo.put("ldap_groups", user.getLdapGroups());
        
        return Jwts.builder()
            .setIssuer("PMS-System")
            .setSubject(user.getUsername())
            .setAudience("Document-System")
            .setIssuedAt(now)
            .setExpiration(expiry)
            .setId(UUID.randomUUID().toString())
            .claim("user_info", userInfo)
            .claim("target_page", targetPage)
            .claim("context", context)
            .signWith(SignatureAlgorithm.HS256, jwtSecret)
            .compact();
    }
    
    private List<String> getUserPermissions(User user) {
        // 根据用户角色获取权限列表
        return user.getRoles().stream()
            .flatMap(role -> role.getPermissions().stream())
            .map(Permission::getName)
            .distinct()
            .collect(Collectors.toList());
    }
}
```

### 3.3 第二个系统实现

#### 3.3.1 JWT验证服务

```java
@Service
public class CrossSystemTokenService {
    
    @Value("${jwt.secret}")
    private String jwtSecret;
    
    @Autowired
    private UserRepository userRepository;
    
    @Autowired
    private RoleRepository roleRepository;
    
    public CrossSystemUserInfo validateAndExtractUserInfo(String token) {
        try {
            Claims claims = Jwts.parser()
                .setSigningKey(jwtSecret)
                .parseClaimsJws(token)
                .getBody();
            
            // 验证Token有效性
            if (claims.getExpiration().before(new Date())) {
                throw new TokenExpiredException("Token已过期");
            }
            
            if (!"PMS-System".equals(claims.getIssuer()) || 
                !"Document-System".equals(claims.getAudience())) {
                throw new InvalidTokenException("Token来源或目标不匹配");
            }
            
            // 提取用户信息
            Map<String, Object> userInfo = (Map<String, Object>) claims.get("user_info");
            String targetPage = (String) claims.get("target_page");
            Map<String, Object> context = (Map<String, Object>) claims.get("context");
            
            return CrossSystemUserInfo.builder()
                .username((String) userInfo.get("username"))
                .email((String) userInfo.get("email"))
                .displayName((String) userInfo.get("display_name"))
                .department((String) userInfo.get("department"))
                .roles((List<String>) userInfo.get("roles"))
                .permissions((List<String>) userInfo.get("permissions"))
                .ldapGroups((List<String>) userInfo.get("ldap_groups"))
                .targetPage(targetPage)
                .context(context)
                .build();
                
        } catch (Exception e) {
            throw new InvalidTokenException("Token验证失败: " + e.getMessage());
        }
    }
}

@Data
@Builder
public class CrossSystemUserInfo {
    private String username;
    private String email;
    private String displayName;
    private String department;
    private List<String> roles;
    private List<String> permissions;
    private List<String> ldapGroups;
    private String targetPage;
    private Map<String, Object> context;
}
```

#### 3.3.2 跨系统登录控制器

```java
@Controller
@RequestMapping("/auth")
public class CrossSystemAuthController {
    
    @Autowired
    private CrossSystemTokenService tokenService;
    
    @Autowired
    private UserSyncService userSyncService;
    
    @GetMapping("/cross-system-login")
    public String crossSystemLogin(
            @RequestParam String token,
            @RequestParam(required = false) String redirect,
            HttpServletRequest request,
            HttpServletResponse response) {
        
        try {
            // 验证Token并提取用户信息
            CrossSystemUserInfo userInfo = tokenService.validateAndExtractUserInfo(token);
            
            // 同步用户到本地系统
            User localUser = userSyncService.syncCrossSystemUser(userInfo);
            
            // 创建Spring Security认证会话
            createAuthenticationSession(localUser, request);
            
            // 重定向到目标页面
            String targetUrl = StringUtils.hasText(redirect) ? redirect : "/dashboard";
            return "redirect:" + targetUrl;
            
        } catch (Exception e) {
            log.error("跨系统登录失败", e);
            return "redirect:/login?error=cross_system_auth_failed";
        }
    }
    
    private void createAuthenticationSession(User user, HttpServletRequest request) {
        // 创建Spring Security认证对象
        List<GrantedAuthority> authorities = user.getRoles().stream()
            .map(role -> new SimpleGrantedAuthority(role.getName()))
            .collect(Collectors.toList());
            
        UserDetails userDetails = new org.springframework.security.core.userdetails.User(
            user.getUsername(), "N/A", authorities);
            
        UsernamePasswordAuthenticationToken auth = 
            new UsernamePasswordAuthenticationToken(userDetails, null, authorities);
            
        SecurityContextHolder.getContext().setAuthentication(auth);
        
        // 保存到Session
        HttpSession session = request.getSession(true);
        session.setAttribute(HttpSessionSecurityContextRepository.SPRING_SECURITY_CONTEXT_KEY,
            SecurityContextHolder.getContext());
    }
}
```

#### 3.3.3 用户同步服务

```java
@Service
@Transactional
public class UserSyncService {

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private RoleRepository roleRepository;

    public User syncCrossSystemUser(CrossSystemUserInfo userInfo) {
        // 查找或创建本地用户
        User localUser = userRepository.findByUsername(userInfo.getUsername())
            .orElseGet(() -> createNewUser(userInfo));

        // 同步用户基本信息
        localUser.setEmail(userInfo.getEmail());
        localUser.setDisplayName(userInfo.getDisplayName());
        localUser.setDepartment(userInfo.getDepartment());
        localUser.setAuthType("CROSS_SYSTEM");
        localUser.setEnabled(true);

        // 同步角色权限
        syncUserRoles(localUser, userInfo.getRoles());

        return userRepository.save(localUser);
    }

    private User createNewUser(CrossSystemUserInfo userInfo) {
        User user = new User();
        user.setUsername(userInfo.getUsername());
        user.setEmail(userInfo.getEmail());
        user.setDisplayName(userInfo.getDisplayName());
        user.setDepartment(userInfo.getDepartment());
        user.setAuthType("CROSS_SYSTEM");
        user.setEnabled(true);
        user.setCreatedAt(new Date());
        return user;
    }

    private void syncUserRoles(User user, List<String> roleNames) {
        Set<Role> roles = new HashSet<>();
        for (String roleName : roleNames) {
            Role role = roleRepository.findByName(roleName)
                .orElseGet(() -> createRoleIfNotExists(roleName));
            roles.add(role);
        }
        user.setRoles(roles);
    }

    private Role createRoleIfNotExists(String roleName) {
        Role role = new Role();
        role.setName(roleName);
        role.setDescription("从PMS系统同步的角色");
        return roleRepository.save(role);
    }
}
```

#### 4.1.2 权限映射服务

```java
@Service
public class PermissionMappingService {

    @Value("#{${cross-system.role-mapping}}")
    private Map<String, String> roleMappingConfig;

    @Value("#{${cross-system.permission-mapping}}")
    private Map<String, String> permissionMappingConfig;

    public List<String> mapRoles(List<String> pmsRoles) {
        return pmsRoles.stream()
            .map(role -> roleMappingConfig.getOrDefault(role, role))
            .distinct()
            .collect(Collectors.toList());
    }

    public List<String> mapPermissions(List<String> pmsPermissions) {
        return pmsPermissions.stream()
            .map(permission -> permissionMappingConfig.getOrDefault(permission, permission))
            .distinct()
            .collect(Collectors.toList());
    }

    public boolean hasPermission(User user, String requiredPermission) {
        return user.getRoles().stream()
            .flatMap(role -> role.getPermissions().stream())
            .anyMatch(permission -> permission.getName().equals(requiredPermission));
    }
}
```

#### 4.2.2 自定义权限评估器

```java
@Component("permissionEvaluator")
public class CustomPermissionEvaluator implements PermissionEvaluator {

    @Autowired
    private PermissionMappingService permissionMappingService;

    @Override
    public boolean hasPermission(Authentication authentication, Object targetDomainObject, Object permission) {
        if (authentication == null || !authentication.isAuthenticated()) {
            return false;
        }

        User user = getCurrentUser(authentication);
        String requiredPermission = permission.toString();

        return permissionMappingService.hasPermission(user, requiredPermission);
    }

    @Override
    public boolean hasPermission(Authentication authentication, Serializable targetId, String targetType, Object permission) {
        return hasPermission(authentication, null, permission);
    }

    private User getCurrentUser(Authentication authentication) {
        String username = authentication.getName();
        return userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("用户不存在: " + username));
    }
}
```

## 5. 安全性保障

### 5.1 Token安全策略

#### 5.1.1 Token加密和签名

```java
@Configuration
public class JwtSecurityConfig {

    @Value("${jwt.secret}")
    private String jwtSecret;

    @Value("${jwt.encryption.key}")
    private String encryptionKey;

    // 使用AES加密Token内容
    public String encryptToken(String token) {
        try {
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
            cipher.init(Cipher.ENCRYPT_MODE, keySpec);

            byte[] encryptedData = cipher.doFinal(token.getBytes());
            return Base64.getEncoder().encodeToString(encryptedData);
        } catch (Exception e) {
            throw new RuntimeException("Token加密失败", e);
        }
    }

    public String decryptToken(String encryptedToken) {
        try {
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
            cipher.init(Cipher.DECRYPT_MODE, keySpec);

            byte[] decryptedData = cipher.doFinal(Base64.getDecoder().decode(encryptedToken));
            return new String(decryptedData);
        } catch (Exception e) {
            throw new RuntimeException("Token解密失败", e);
        }
    }
}
```

```java
@Service
public class TokenUsageService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String TOKEN_USAGE_PREFIX = "token:usage:";
    private static final int MAX_USAGE_COUNT = 1; // Token只能使用一次

    public boolean isTokenUsed(String tokenId) {
        String key = TOKEN_USAGE_PREFIX + tokenId;
        return redisTemplate.hasKey(key);
    }

    public void markTokenAsUsed(String tokenId, int expireSeconds) {
        String key = TOKEN_USAGE_PREFIX + tokenId;
        redisTemplate.opsForValue().set(key, "used", expireSeconds, TimeUnit.SECONDS);
    }

    public boolean canUseToken(String tokenId) {
        return !isTokenUsed(tokenId);
    }
}
```

```javascript
// 第二个系统 - 处理跨系统登录
class CrossSystemAuthHandler {

    constructor() {
        this.handleCrossSystemAuth();
    }

    handleCrossSystemAuth() {
        const urlParams = new URLSearchParams(window.location.search);
        const token = urlParams.get('token');
        const redirect = urlParams.get('redirect');

        if (token) {
            // 显示登录中状态
            this.showLoginProgress();

            // 自动提交跨系统登录
            this.submitCrossSystemLogin(token, redirect);
        }
    }

    async submitCrossSystemLogin(token, redirect) {
        try {
            const form = document.createElement('form');
            form.method = 'GET';
            form.action = '/auth/cross-system-login';

            const tokenInput = document.createElement('input');
            tokenInput.type = 'hidden';
            tokenInput.name = 'token';
            tokenInput.value = token;
            form.appendChild(tokenInput);

            if (redirect) {
                const redirectInput = document.createElement('input');
                redirectInput.type = 'hidden';
                redirectInput.name = 'redirect';
                redirectInput.value = redirect;
                form.appendChild(redirectInput);
            }

            document.body.appendChild(form);
            form.submit();

        } catch (error) {
            console.error('跨系统登录失败:', error);
            this.showError('登录失败，请重试');
```

### 7.2 安全配置清单

1. **JWT密钥管理**
   - 使用强随机密钥（至少256位）
   - 定期轮换密钥
   - 密钥存储在环境变量或密钥管理服务中

2. **网络安全**
   - 系统间通信使用HTTPS
   - 配置防火墙规则，限制系统间访问
   - 使用VPN或内网隔离

3. **访问控制**
