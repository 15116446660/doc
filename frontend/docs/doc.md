# AI助手需求文档

基于OnlyOffice开发的企业内部Word等文档的多人协同编辑平台基础功能需求。

## 功能需求说明

### 1. AI内容反插入文档
通过检查结果准确定位到相关问题所在位置，可以实现将AI检查的结果通过人工确认后，即可把检查修改建议的正确内容进行反向插入到文档问题所在位置处(可以参照Office AI的AI校对功能)。

**详细需求：**
- 实现对文档内容的自动切片与错误内容定位
- 基于AI模型生成针对错别字与语句不通的纠错建议
- 支持用户交互式选择纠错方案，并智能填入原始文档，实现内容反插入
- 处理流程：用户输入→文档切片与预处理模块→切片的错误检测与定位→AI模型生成切片的纠错建议→用户交互选择→切片的内容反插入与文档重构→输出修正文档

**核心功能点：**
- 文档切片及其索引管理：将原始文档中的内容进行自动化读取与预处理，去除无效格式信息后，按规则对文档进行语义切片，并为每个切片分配唯一标识与多维索引信息
- 错误检测：自动检测切片中的文本错误，包括错别字、语法不通、逻辑混乱等内容问题
- AI智能纠错建议生成：结合上下文和语言模型能力，为检测出的错误内容提供智能修复建议，供用户选择
- 内容反插入与文档重构：将用户选择的纠错建议精确填入原始文档中的错误位置，实现"反插入"式内容修复
- 修正文档展示：将经过错误检测与内容修复后的文档，以用户友好、格式多样的方式输出

### 2. 切片智能打标
提升素材召回率。

**详细需求：**
- 自动完成文档的切片与结构化存储
- 借助AI模型对切片进行多维语义标签的智能生成
- 基于上下文语义与标题信息，提供高质量的切片检索支持
- 总体流程：用户输入→文档解析与切片→切片知识库管理→向量化编码、知识库存储与索引→AI模型自动打标→切片智能检索模块→检索结果输出

**核心功能点：**
- 文档预处理：清洗原始数据，统一格式，为后续切片做准备
- 切片与索引管理：将文档按语义或结构单元切片，并构建多维度索引
- AI智能打标模块：利用大模型对每个切片进行多标签自动打标，增强语义理解
- 知识库存储结构：将结构化文本、向量及元信息存储，支持高效检索
- 智能检索模块：根据输入内容检索最相关切片并返回
- 结果展示与筛选：将召回内容展示给用户，并提供交互式筛选机制

### 3. 提示词工具
一个提示词测试多个文件，来验证提示词应用效果；以及多个提示词测试同一个文档来验证不同提示词应用效果。

**详细需求：**
- 构建一个基于Langfuse的提示词测试与评估系统，支持提示词的批量管理、模型调用、交互结果追踪与多维评估
- 实现双向提示词验证：单提示词-多文档测试和多提示词-单文档测试

**核心功能点：**
- 文档预处理及其切片模块：自动化读取并预处理文档内容，去除无效格式信息后对文档进行语义切片
- 提示词管理与配置模块：支持提示词的标准化管理与测试参数配置，便于后续测试任务的自动化调度
- 测试执行引擎模块：调度模型对提示词与文档切片的组合输入进行批量测试，记录输出、异常和交互日志
- 结果管理与可视化展示：将测试结果结构化存储并提供可视化比对与多维分析能力，支持人工或模型辅助评分

### 4. 引用源标记
对引用的内容在文件中批注引用的文件名称和文件章节编号和标题信息(原文部分信息)。

**详细需求：**
- 优化文档中切片的引用标记与溯源机制，确保每个切片的推荐与使用都能准确关联到原始分片的元数据
- 生成批注或结构化引用标记，实现内容的自动化标记和追溯

**核心功能点：**
- 文档解析与切片索引管理：对输入文档进行切片，按照语义和内容进行分段，每个切片都单独存储，并作为独立的单位保存在本地知识库中
- 切片推荐模块：通过文档的上下文、标题以及其他语境信息，从本地知识库中推荐出Top-N最相似的切片
- 引用源自动标记与批量回写：对于每段改写结果，系统会自动插入引用标记，包括文件名、章节/标题路径、分片ID、原文片段摘要
- 本地化执行与日志记录：整个流程在本地完成，所有操作过程均在本地环境中完成，避免数据泄露或服务中断的风险

### 5. AI智能排版
可将OnlyOffice中的文件内容实现自动化排版(可以参照Office AI的AI校对功能，但不太理想)。

**详细需求：**
- 通过自然语言处理（NLP）、模式识别、自动模板匹配和AI编程能力，解决文档排版中的重复性工作
- 提升排版效率和文档质量

**核心功能点：**
- 文档内容预处理及切片：为后续排版步骤打好基础，分为文档级和切片级，确保文档内容的结构化和可处理性
- 使用大模型选取文档中的相关切片：自动识别并分类文档内容，依据用户修改需求选取相关切片
- 基于规则模板与大模型对所选切片进行统一处理：通过规则模板和大模型，自动调整并统一所选切片的格式
- 人工校对与可视化交互：兼顾自动与人工，提升最终文档排版质量

### 6. 长文本交互
能够读到长文本所有内容，并实现对长文本检查、概括、改写、复杂表单等一系列相关交互。

**详细需求：**
- 支持长文本的完整读取、内容理解与多轮交互操作，依托千问大模型的语言能力，解决长文本处理中的语义理解与信息提取问题

**核心功能点：**
- 支持长文本的完整接入与分段解析：能够有效处理超长文本，确保文本中每一部分的结构和语义信息得到保留
- 实现对长文本的语义检查、错别字识别、逻辑评估：提供文本质量检查，包括语法错误、逻辑不一致以及错别字识别
- 从文中提取结构化信息：提取并处理文中的复杂表格、表单字段、条款等结构化信息，便于后续处理和分析
- 文档结构解析与智能切片模块：解析用户上传的长文本，保留文档结构和语义信息，生成适合模型处理的切片
- 多任务智能处理模块：基于千问大模型，实现多任务智能处理，满足切片的检查、概况和结构化信息提取等需求
- 基于千问大模型的文本理解与表格生成：处理超长文本，通过大模型生成表格数据，提供准确的答案和结构化的信息
- 基于千问大模型的多轮问答：提供多轮问答能力，使得每一轮的问答基于上下文和之前的回答生成准确且连贯的回复

### 7. 对比差异
可以参考行业做得好的工具(如GIT)实现相关效果。

**详细需求：**
- 结构化对比两份或多份文档内容，智能识别并呈现文档间的差异
- 支持逐字符或逐语义单元比对，标记文本增删改、段落结构变化、格式调整和引用源差异等

**核心功能点：**
- 内容对比：识别文本内容的增加、删除、修改
- 结构化元素对比：比较表格、列表、标题等结构化元素的变化
- 格式差异对比：检测字体、样式、对齐方式等格式变化
- 引用源一致性对比：比较引用信息的变化
- 版本历史追溯：支持多版本文档的历史对比
- 文档预处理：将不同格式的文档转换为统一的中间结构，便于后续算法处理
- 差异检测：基于Myers差分算法识别文本差异，结合规则引擎定位结构化差异
- 差异分析：将原始差异标记映射到用户可理解的文档逻辑单元
- 结果渲染：将差异结果以高可读性形式展示，支持用户交互与导出
