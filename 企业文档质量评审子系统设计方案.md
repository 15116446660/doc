# 企业文档质量评审子系统设计方案

## 1. 系统概述

基于现有的企业文档管理系统架构，重新设计企业文档质量评审子系统，实现完整的文档审核流程管理。系统将与现有的OnlyOffice深度集成，充分利用已有的7个AI核心功能，构建智能化的评审协同平台。

## 2. 核心设计原则

### 2.1 架构一致性
- 保持与现有Vue3 + Spring Boot技术栈的一致性
- 复用现有的用户管理、权限控制、文档管理等基础模块
- 扩展现有的AI功能，增强评审智能化水平

### 2.2 业务连续性
- 基于现有的ReviewTask、ReviewComment等实体模型进行扩展
- 保持与现有项目管理、文档库的无缝集成
- 支持现有评审流程的平滑升级

### 2.3 可扩展性
- 采用模块化设计，支持功能的独立部署和扩展
- 提供标准化的API接口，便于第三方系统集成
- 支持多租户和国际化需求

```java
@Service
public class NodeRoutingService {

    public List<User> routeToNextNode(ReviewWorkflowInstance instance, String nodeId) {
        WorkflowNode node = getNodeDefinition(instance.getTemplateId(), nodeId);

        switch (node.getNodeType()) {
            case SEQUENTIAL:
                return routeSequential(node);
            case PARALLEL:
                return routeParallel(node);
            case CONDITIONAL:
                return routeConditional(node, instance);
            default:
                throw new UnsupportedOperationException("Unsupported node type: " + node.getNodeType());
        }
    }

    private List<User> routeConditional(WorkflowNode node, ReviewWorkflowInstance instance) {
        // 解析条件表达式
        String condition = node.getConditions();
        boolean conditionMet = evaluateCondition(condition, instance);

        if (conditionMet) {
            return expertRecommendationService.recommendExperts(
                instance.getReviewTaskId(),
                node.getRequiredExpertise()
            );
        } else {
            // 跳转到备选节点
            return routeToNextNode(instance, node.getAlternativeNodeId());
        }
    }
}
```

### 7.2 专家推荐算法实现

#### 7.2.1 多维度匹配算法
```java
@Service
public class ExpertRecommendationService {

    public List<ExpertRecommendation> recommendExperts(Long reviewTaskId, String requiredExpertise) {
        ReviewTask task = reviewTaskRepository.findById(reviewTaskId).orElseThrow();
        Document document = task.getDocument();

        // 1. 获取候选专家池
        List<ExpertProfile> candidates = getCandidateExperts(requiredExpertise);

        // 2. 计算匹配分数
        List<ExpertRecommendation> recommendations = candidates.stream()
            .map(expert -> calculateMatchScore(expert, document, task))
            .filter(rec -> rec.getMatchScore() > 0.6) // 过滤低匹配度
            .sorted((a, b) -> Double.compare(b.getMatchScore(), a.getMatchScore()))
            .limit(10)
            .collect(Collectors.toList());

        // 3. 冲突检测和回避
        return filterConflicts(recommendations, task);
    }

    private ExpertRecommendation calculateMatchScore(ExpertProfile expert, Document document, ReviewTask task) {
        double expertiseScore = calculateExpertiseMatch(expert, document);
        double workloadScore = calculateWorkloadScore(expert);
        double performanceScore = expert.getAverageScore() / 5.0;
        double availabilityScore = calculateAvailabilityScore(expert, task.getDeadline());

        // 加权计算总分
        double totalScore = expertiseScore * 0.4 +
                           workloadScore * 0.2 +
                           performanceScore * 0.3 +
                           availabilityScore * 0.1;

        return new ExpertRecommendation(expert, totalScore);
    }

    private double calculateExpertiseMatch(ExpertProfile expert, Document document) {
        // 使用AI分析文档内容与专家专业领域的匹配度
        return aiAnalysisService.calculateExpertiseMatch(
            expert.getSpecialtyAreas(),
            document.getContent()
        );
    }
}
```

```java
@Service
public class AIRiskDetectionService {

    public List<AIRiskAnalysis> detectRisks(Long reviewTaskId) {
        ReviewTask task = reviewTaskRepository.findById(reviewTaskId).orElseThrow();
        Document document = task.getDocument();

        List<AIRiskAnalysis> risks = new ArrayList<>();

        // 1. 合规风险检测
        risks.addAll(detectComplianceRisks(document));

        // 2. 事实准确性检测
        risks.addAll(detectFactualRisks(document));

        // 3. 格式规范检测
        risks.addAll(detectFormatRisks(document));

        // 4. 敏感信息检测
        risks.addAll(detectSensitiveInfoRisks(document));

        return risks.stream()
            .filter(risk -> risk.getConfidenceScore() > 0.7)
            .collect(Collectors.toList());
    }

    private List<AIRiskAnalysis> detectComplianceRisks(Document document) {
        // 调用千问AI进行合规性分析
```

```java
        // 智能切片标记 → 重点关注区域
        suggestions.addAll(generateFocusAreaSuggestions(document));

        // AI内容反向插入 → 内容改进建议
        suggestions.addAll(generateContentImprovementSuggestions(document));

        // 引用来源标记 → 引用规范建议
        suggestions.addAll(generateCitationSuggestions(document));

        // AI智能格式化 → 格式优化建议
        suggestions.addAll(generateFormatSuggestions(document));

        return suggestions;
    }

    private List<ReviewSuggestion> generateFocusAreaSuggestions(Document document) {
        // 调用智能切片标记功能
        AIAnalysisResult sliceResult = aiAnalysisService.performSliceTagging(document);

        return parseSliceResults(sliceResult).stream()
            .map(slice -> new ReviewSuggestion(
                "FOCUS_AREA",
                "建议重点关注：" + slice.getDescription(),
                slice.getPosition(),
                SuggestionPriority.HIGH
            ))
            .collect(Collectors.toList());
    }
}
```

#### 7.5.1 SLA监控实现
```java
@Service
@Scheduled
public class SLAMonitoringService {

    @Scheduled(fixedRate = 60000) // 每分钟检查一次
    public void monitorSLAViolations() {
        List<ReviewWorkflowInstance> runningInstances =
            workflowInstanceRepository.findByWorkflowStatus(WorkflowStatus.RUNNING);

        for (ReviewWorkflowInstance instance : runningInstances) {
            checkNodeSLA(instance);
        }
    }

    private void checkNodeSLA(ReviewWorkflowInstance instance) {
        String currentNodeId = instance.getCurrentNodeId();
        WorkflowNode node = getNodeDefinition(instance.getTemplateId(), currentNodeId);

        LocalDateTime nodeStartTime = getNodeStartTime(instance, currentNodeId);
        Duration elapsed = Duration.between(nodeStartTime, LocalDateTime.now());
        Duration slaLimit = Duration.ofHours(node.getSlaHours());

        if (elapsed.compareTo(slaLimit) > 0) {
            handleSLAViolation(instance, node, elapsed);
        } else if (elapsed.compareTo(slaLimit.multipliedBy(80).dividedBy(100)) > 0) {
            // 80%时间已过，发送提醒
            sendSLAWarning(instance, node, elapsed);
        }
    }

    private void handleSLAViolation(ReviewWorkflowInstance instance, WorkflowNode node, Duration elapsed) {
        // 1. 记录SLA违规
        SLAViolation violation = new SLAViolation(instance.getId(), node.getNodeId(), elapsed);
        slaViolationRepository.save(violation);

        // 2. 自动升级处理
        if (node.isAutoEscalationEnabled()) {
            escalateToSupervisor(instance, node);
        }

        // 3. 发送告警通知
        sendSLAViolationAlert(instance, node, elapsed);
    }

    private void escalateToSupervisor(ReviewWorkflowInstance instance, WorkflowNode node) {
        // 查找当前审核人的上级
        List<User> currentReviewers = getCurrentReviewers(instance, node.getNodeId());
        List<User> supervisors = userService.getSupervisors(currentReviewers);

        // 创建升级任务
        for (User supervisor : supervisors) {
            ReviewTaskAssignment escalationAssignment = new ReviewTaskAssignment();
            escalationAssignment.setReviewTaskId(instance.getReviewTaskId());
            escalationAssignment.setAssigneeId(supervisor.getId());
            escalationAssignment.setAssignmentType(AssignmentType.ESCALATION);
            escalationAssignment.setDueDate(LocalDateTime.now().plusHours(node.getEscalationSlaHours()));

            reviewTaskAssignmentRepository.save(escalationAssignment);
        }

        // 发送升级通知
        notificationService.sendEscalationNotification(supervisors, instance);
    }
}
```

```java
@Service
public class NotificationService {

    public void sendReviewAssignmentNotification(User assignee, ReviewTask task) {
        NotificationRequest request = NotificationRequest.builder()
            .recipient(assignee)
            .subject("新的文档评审任务")
            .content(buildAssignmentContent(task))
            .priority(NotificationPriority.HIGH)
            .channels(determineNotificationChannels(assignee, task))
            .build();

        sendNotification(request);
    }

    private List<NotificationChannel> determineNotificationChannels(User user, ReviewTask task) {
        List<NotificationChannel> channels = new ArrayList<>();

        // 基于任务优先级和用户偏好确定通知渠道
        if (task.getPriority() == ReviewTaskPriority.URGENT) {
            channels.add(NotificationChannel.SMS);
            channels.add(NotificationChannel.WECHAT_WORK);
        }

        channels.add(NotificationChannel.EMAIL);
        channels.add(NotificationChannel.IN_APP);

        // 根据用户偏好过滤
        return channels.stream()
            .filter(channel -> user.getNotificationPreferences().isEnabled(channel))
            .collect(Collectors.toList());
    }

    private void sendNotification(NotificationRequest request) {
        for (NotificationChannel channel : request.getChannels()) {
            try {
                switch (channel) {
                    case EMAIL:
                        emailService.sendEmail(request);
                        break;
                    case SMS:
                        smsService.sendSMS(request);
                        break;
                    case WECHAT_WORK:
                        wechatWorkService.sendMessage(request);
                        break;
                    case IN_APP:
                        inAppNotificationService.sendNotification(request);
                        break;
                }
            } catch (Exception e) {
                log.error("Failed to send notification via {}: {}", channel, e.getMessage());
                // 记录失败，但不影响其他渠道
            }
        }
    }
}
```

### 9.1 数据加密
```java
@Component
public class DocumentEncryptionService {

    @Value("${app.encryption.key}")
    private String encryptionKey;

    public String encryptSensitiveContent(String content) {
        try {
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
            cipher.init(Cipher.ENCRYPT_MODE, keySpec);

            byte[] encryptedBytes = cipher.doFinal(content.getBytes(StandardCharsets.UTF_8));
            return Base64.getEncoder().encodeToString(encryptedBytes);
        } catch (Exception e) {
            throw new RuntimeException("Encryption failed", e);
        }
    }

    public String decryptSensitiveContent(String encryptedContent) {
        try {
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            SecretKeySpec keySpec = new SecretKeySpec(encryptionKey.getBytes(), "AES");
            cipher.init(Cipher.DECRYPT_MODE, keySpec);

            byte[] decryptedBytes = cipher.doFinal(Base64.getDecoder().decode(encryptedContent));
            return new String(decryptedBytes, StandardCharsets.UTF_8);
        } catch (Exception e) {
            throw new RuntimeException("Decryption failed", e);
        }
    }
}
```
